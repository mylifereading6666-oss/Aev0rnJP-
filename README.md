# Aev0rnJP Roulette

迷ったときに、候補を登録してルーレットで決められる、無料のシンプルなルーレットアプリです。スマートフォン・パソコンのブラウザで利用できます。Android版はWebViewアプリとして、ウェブ版を表示します。

## ウェブ版を使う

**公開ページ：** https://mylifereading6666-oss.github.io/Aev0rnJP-/

ページを開くと、初期サンプルの候補が表示されます。自分の候補に入れ替えて使ってください。

## Androidアプリ（APK）を直接ダウンロード

**[ここを押してAPKをダウンロード](https://github.com/mylifereading6666-oss/Aev0rnJP-/releases/latest/download/Aev0rnJP-Roulette.apk)**

Android端末で上のリンクを押すと、公開済みの最新APKのダウンロードが始まります。Google PlayではなくGitHubから配布しています。初回は、ビルドが成功してAPKがGitHub Releasesに公開された後に利用できます。

インストール時に許可を求められた場合は、ダウンロード元アプリからのインストールをAndroidの設定で許可してください。アプリはウェブ版を表示するため、利用にはインターネット接続が必要です。

**ダウンロードできない場合：** まだAPKがリリースされていないか、最新ビルドが失敗している可能性があります。ビルド状況は [GitHub Actions](https://github.com/mylifereading6666-oss/Aev0rnJP-/actions) で確認できます。

## 基本的な使い方

1. **候補を追加する**  
   「候補リスト」の入力欄に候補名を入力し、「追加」を押します。候補は最大100個、候補名は最大80文字です。
2. **候補を編集・削除する**  
   各候補の「編集」で名前を変更できます。「✕」でその候補だけを削除できます。
3. **ルーレットを回す**  
   候補を2つ以上用意して、「ルーレットを回す」を押します。回転が終わると結果が表示されます。
4. **抽選後の動作を設定する**  
   「抽選後」で「候補を残す」か「当選者を削除」を選べます。
5. **回転時間を変更する**  
   3秒・5秒・8秒・12秒から選べます。
6. **効果音を設定する**  
   「効果音」のチェックを切り替えられます。
7. **候補を並べ替える**  
   「シャッフル」で順番をランダムにし、「名前順」で名前順に並べられます。「サンプル」は候補を「はい・いいえ・保留」に置き換えます。「全削除」は候補をすべて削除します。
8. **抽選履歴を確認する**  
   最近の当選結果を確認できます。「履歴削除」で履歴を消去できます。

## 重み付けモード

通常は各候補が同じ重みで抽選されます。「重み付けモード」をオンにすると、候補ごとに設定した重みに応じて選ばれやすさが変わります。重みは1〜100です。

右側の「コマンド入力」欄から設定できます。

| コマンド | 内容 |
| --- | --- |
| `/help` | コマンド一覧を表示 |
| `/weight "候補名" 10` | 指定した候補の重みを10に設定（1〜100） |
| `/weights on` | 重み付け抽選を有効化 |
| `/weights off` | 均等確率に切り替え。重みの数値は保持 |
| `/weights list` | 候補ごとの重みを表示 |
| `/weights reset` | 全候補の重みを1に戻す |

例：候補名が「りんご」の場合、`/weight "りんご" 5` と入力すると、りんごの重みを5に設定します。重み付けを使うには「重み付けモード」をオンにしてください（`/weight` コマンドから設定した場合は自動でオンになります）。

## バックアップとデータ保存

- 候補リストと抽選履歴は、利用しているブラウザの端末内ストレージに保存されます。
- **別の端末・ブラウザには自動同期されません。**
- ブラウザのデータやサイトデータを消去すると、保存内容が消えることがあります。
- 大切な候補は「バックアップ保存」でJSONファイルに保存してください。
- 復元するときは「バックアップ読込」から保存したJSONファイルを選びます。
- バックアップには候補と抽選履歴が含まれます。読み込むと現在の候補・履歴が置き換わります。

## プライバシーについて

ルーレットの候補と履歴はブラウザ内に保存され、ルーレット機能自体はアカウント登録を必要としません。端末内に保存されるデータを守るため、共有端末では利用後のデータ管理に注意してください。
